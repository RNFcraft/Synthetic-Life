# Synthetic-Life v0.9 --- Адаптивный мир и обучение

## Обзор

v0.9 является переходом от реактивного организма к обучающемуся
организму.

После завершения v0.8 Synthetic-Life получает:

-   внутреннюю физиологию;
-   базовые потребности;
-   homeostatic tension;
-   мотивацию действий через внутреннее состояние;
-   связь действий с последствиями.

Однако такой организм всё ещё находится в слишком простом мире.

Цель v0.9:

Создать полноценную детерминированную 2D-среду, в которой агент сможет
самостоятельно изучать свойства объектов, открывать возможности
взаимодействия, строить причинные связи и формировать устойчивые модели
поведения.

------------------------------------------------------------------------

# Основные принципы

## 1. Разделение знаний мира и знаний организма

Мир обладает объективными свойствами.

Например:

    Wood:
        flammable = true

Но организм не получает эту информацию напрямую.

Он получает только:

-   сенсорные данные;
-   выполненное действие;
-   полученное последствие.

Знание должно появляться через собственный опыт.

Пример:

    объект
    +
    действие
    +
    результат

    ↓

    изученная связь

------------------------------------------------------------------------

## 2. Отсутствие внешней системы наград

v0.9 не использует:

-   искусственные reward points;
-   заранее заданное поведение;
-   человеческие метки;
-   готовые решения.

Обучение происходит через:

    Опыт
    ↓
    Предсказание
    ↓
    Ошибка предсказания
    ↓
    Обновление знаний
    ↓
    Изменение будущего поведения

Цель --- не заставить агента делать правильные действия, а создать
условия, где правильные действия появляются из опыта.

# Структура v0.9

------------------------------------------------------------------------

# v0.9.0 --- Основа 2D World Engine

## Цель

Создать расширяемый детерминированный 2D-мир.

Текущая модель:

    Entity
    Food
    Position

должна перейти к:

    World

    ├── Terrain
    ├── Objects
    ├── Entities
    ├── Materials
    ├── Properties
    ├── Interactions
    ├── Events
    └── Persistence

------------------------------------------------------------------------

## Объекты мира

Каждый объект должен иметь:

-   уникальный идентификатор;
-   позицию;
-   состояние;
-   материал;
-   свойства.

Пример:

    Tree

    material:
        wood

    properties:
        breakable
        movable
        flammable

Свойства существуют только на уровне мира.

Организм должен открывать их самостоятельно.

------------------------------------------------------------------------

## Система взаимодействий

Общая модель:

    Entity
    +
    Action
    +
    Object
    =
    World consequence

Примеры:

-   перемещение;
-   касание;
-   поднятие;
-   перенос;
-   употребление;
-   соединение объектов.

------------------------------------------------------------------------

# v0.9.1 --- Research Observer и World Editor

## Цель

Создать исследовательский интерфейс для наблюдения и экспериментов.

Это не игровой редактор.

Это лаборатория для изучения поведения.

------------------------------------------------------------------------

## Основная структура интерфейса

    WORLD EDITOR

    DIALOGUE | WORLD | BRAIN

    STATUS / INSPECTOR

    TIMELINE

------------------------------------------------------------------------

## Возможности редактора мира

Пользователь может:

-   создавать объекты;
-   перемещать объекты;
-   удалять объекты;
-   просматривать свойства объектов.

Все изменения проходят через:

    UI
    ↓
    External Event
    ↓
    Scheduler
    ↓
    World

Интерфейс не должен напрямую изменять внутреннее состояние мозга.

------------------------------------------------------------------------

## Observer

Должен отображать:

-   текущее действие;
-   текущую цель;
-   физиологическое состояние;
-   активные Cognits;
-   Relations;
-   Assemblies;
-   нейродинамическую активность.

------------------------------------------------------------------------

## Timeline

Отображение причинной цепочки:

    Сенсорное событие
    ↓
    Нейронная активность
    ↓
    Изменение Cognition
    ↓
    Решение Planner
    ↓
    Действие
    ↓
    Последствие в мире

# v0.9.2 --- Расширенная сенсорная система

## Цель

Перейти от символического восприятия к более реалистичному восприятию
среды.

Сейчас:

    object_id = 15

Будущее:

    Visual pattern:

    форма
    цвет
    расстояние
    движение
    положение

Организм получает не название объекта, а сенсорный паттерн.

Пример:

Мир:

    красный квадрат

Организм:

    определённый визуальный сигнал

Связь между ними формируется обучением.

------------------------------------------------------------------------

# v0.9.3 --- Изучаемые affordances

## Цель

Позволить организму самостоятельно открывать возможности объектов.

Не:

    Food → Eat

А:

    Объект
    +
    Действие
    +
    Последствие

создают знание.

Пример:

    Объект A
    +
    Consume
    ↓
    Энергия увеличилась

После повторения появляется:

    Объект A способен удовлетворить потребность

------------------------------------------------------------------------

Примеры изучаемых возможностей:

-   съедобность;
-   переносимость;
-   полезность;
-   опасность;
-   возможность взаимодействия.

------------------------------------------------------------------------

# v0.9.4 --- Обучение последовательностям действий

## Цель

Перейти от отдельных действий к цепочкам поведения.

Пример:

До обучения:

    MOVE

После опыта:

    MOVE
    MOVE
    GRAB
    RETURN
    CONSUME

Успешные последовательности должны усиливаться через накопление опыта.

На первом этапе не создавать отдельную жёсткую систему Skills.

Использовать существующие механизмы:

-   Cognits;
-   Relations;
-   evidence;
-   prediction.

------------------------------------------------------------------------

# v0.9.5 --- Любопытство и эпистемическая мотивация

## Цель

Создать поведение, которое возникает не только из выживания.

Добавить:

    Epistemic tension

Отдельно от:

    Homeostatic tension

------------------------------------------------------------------------

Homeostatic:

    Мне не хватает энергии.

Epistemic:

    Я не понимаю этот объект.

------------------------------------------------------------------------

Неизвестные элементы мира могут создавать давление на исследование.

Пример:

    Неизвестный объект
    ↓
    Высокая неопределённость
    ↓
    Исследование
    ↓
    Новое знание

------------------------------------------------------------------------

# v0.9.6 --- Причинная модель мира

## Цель

Перейти от простых ассоциаций к причинным связям.

Не:

    A часто рядом с B

А:

    A вызывает B

------------------------------------------------------------------------

Пример:

Эксперимент:

    Fire
    +
    Wood
    ↓
    Ash

Полученное знание:

    Fire изменяет Wood

------------------------------------------------------------------------

Модель должна поддерживать:

-   временные связи;
-   последствия действий;
-   изменения окружающей среды;
-   способность делать предсказания.

------------------------------------------------------------------------
